# Juaquin Arenas — Portfolio Foundation

A first-draft personal portfolio built with React, Vite, and React Router. It has a shared navigation/footer layout and four routes: Home, About, Projects, and Contact. The image frames are intentional placeholders for personal and achievement photos to add later.

## Run locally

```sh
npm install
npm run dev
```

## Build for production

```sh
npm run build
npm run preview
```

## Routes

- `/` — Landing page and highlights
- `/about` — Bio, skills, education, and achievements
- `/projects` — First-draft project cards
- `/contact` — Email and phone links

The project uses CSS scroll reveal effects and respects reduced-motion preferences. Replace the photo placeholders in `src/App.jsx` when your images are ready.
